# Funkot Parties Calendar

日本の Funkot（ファンコット）パーティー予定を自動収集し、購読可能な ICS として公開する。

## 購読（外部カレンダー）

Google / Apple / Outlook などで次の URL を「URL で追加」:

`https://raw.githubusercontent.com/yasuyuki/funkot-calendar/main/funkot-parties.ics`

（更新反映まで数時間かかることがある）

## 中身

- `events.json` … 正本のイベント台帳
- `funkot-parties.ics` … 購読用フィード

旧コミュニティの FUNKOTERカレンダーは閲覧専用で更新が止まっているため、ここが新しい正とする。

## ライセンス

イベント情報は各主催の告知に基づく。このリポジトリのスクリプト／メタデータは CC0。
